# Coffee Shop Landing Page

A modern and responsive coffee shop landing page built using **HTML5 and CSS3**. This project is designed to practice frontend web development, page structure, styling, layouts, and visual presentation.

## Overview

**Coffee Shop Landing Page** is a frontend practice project created to represent a modern coffee shop website.

The page uses coffee and café imagery to create a warm and welcoming design while demonstrating fundamental HTML and CSS skills.

## Features

* Modern coffee shop landing page
* Responsive layout
* Navigation section
* Hero section
* Coffee shop introduction
* Coffee and beverage showcase
* Pastries section
* Café imagery
* Clean typography and spacing
* Styled buttons and sections
* Footer section

## Technologies Used

* HTML5
* CSS3
